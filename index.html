A bedtime-story app for children aged 3 to 8. A parent taps how the day felt, and the app plays a short narrated story that says the child's own name. I built version 2 in Flutter, and the REST API it runs on.

In the app · Flutter

  • Feeling check-in, story player with captions synced to the narration, story library and settings, in day and night themes.
  • Audio playback that lays each child's name over the narration at set moments, lowering the story's volume around it.
  • Google, Apple and email sign-in, and Firebase Cloud Messaging notifications on both platforms.

On the server · Node.js, Express, PostgreSQL

  • REST API on AWS with JWT access and refresh tokens, and a staging server to test each change before release.
  • Guest accounts that let a family try 5 stories, then keep their child's profile when they sign up.
  • Name clips from a text-to-speech API, matched to the stories' loudness, and morning notifications in each family's time zone.
  • Account deletion in one transaction that also revokes Sign in with Apple, as App Store rules require.
